# פריים · סטודיו צילום

אתר לניהול צוות צלמות: לקוחות בוחרות סוג צילום ותאריך, רואות מי פנויה, ושולחות בקשה לצלמת מסוימת או לסטודיו. מנהלת פריים משבצת, עוקבת אחרי יומן משותף ומרוויחה עמלה על כל הפניה.

## שלושה מסכים
| מסך | קובץ | מה יש בו |
|---|---|---|
| לקוחה | `index.html` | אשף הזמנה ב־4 שלבים (סוג צילום, תאריך עם מספר הצלמות הפנויות בכל יום, בחירת צלמת עם סינון לפי אזור/סגנון/תקציב, פרטים). צלמות תפוסות מציעות תאריכים פנויים קרובים. אפשרות "תבחרו בשבילי" ששולחת לסטודיו. רשימת צלמות עם פרופיל ויומן זמינות. |
| ניהול | `admin.html` (קוד דמו: `1234`) | לוח בקרה עם עמלות החודש, "דורש טיפול" (בקשות לשיבוץ, דחיות, בקשות בלי תשובה מעל יממה), תיבת בקשות, שיבוץ לצלמת פנויה בלחיצה + הודעת וואטסאפ מוכנה, יומן חודשי של כל הצלמות, ניהול צלמות (ימי עבודה, אזורים, מחירון, אחוז עמלה), דוח עמלות. |
| צלמת | `portal.html?p=<id>` | בקשות שמחכות לאישור (מאשרת / לא יכולה), הצילומים הקרובים, הכנסה נטו, ויומן זמינות שבו לוחצים על יום כדי לפתוח או לחסום אותו. |

## סוגי צלמות
- **מודל העסקה:** צלמת שעובדת לפי אחוזים (הלקוחות משלמות לה, ורחל מקבלת עמלה), או צלמת שמקבלת משכורת חודשית (ההכנסה מהצילומים שלה הולכת לרחל, והמשכורת יורדת מהרווח).
- **היקף עבודה:** צלמת שעושה תהליך מלא (מצלמת, עורכת ומעצבת לבד), או צלמת שרק מצלמת ומעבירה חומרים, והעריכה והעיצוב עוברים לסטודיו.
- **עריכה ומסירה:** אחרי כל צילום הוא עובר שלבים: ממתין לחומרים, עריכה, עיצוב, נמסר. כל שלב שייך למי שאחראית עליו, עם תאריך יעד למסירה (45 יום לחתונה, 30 לבר מצווה, 21 לשאר). איחורים קופצים ב"דורש טיפול".

## לוגיקת זמינות
- לכל צלמת יש ימי עבודה קבועים, ובנוסף ימים שנפתחו או נחסמו ידנית.
- כל יום מחולק לשתי משבצות: צילום קצר תופס משבצת אחת, אירוע (חתונה, בר מצווה) תופס את היום כולו.
- בקשה שנשלחה לצלמת שומרת לה את התאריך עד שהיא עונה. אם היא דוחה, התאריך משתחרר והבקשה חוזרת לשיבוץ.

## דמו
הנתונים נשמרים ב־`localStorage`, כלומר רק בדפדפן שבו פותחים את האתר. הכפתור "איפוס" בסרגל העליון מחזיר את נתוני הדוגמה. השמות והתמונות הם לדוגמה בלבד (התמונות מגיעות מ־picsum.photos).

## לגרסה אמיתית
- מסד נתונים משותף (Supabase או Firebase) במקום localStorage, כדי שכולן יראו את אותו יומן.
- כניסה אמיתית לצלמות ולמנהלת.
- התראות אוטומטיות בוואטסאפ ובמייל (WhatsApp Business API), ותזכורת ללקוחה יום לפני הצילום.
- גביית מקדמה אונליין, ודוח עמלות חודשי לכל צלמת.
- ביקורות מלקוחות וגלריית עבודות אמיתית לכל צלמת.

## עדכון גרסה
GitHub Pages שומר קבצים בדפדפן ל־10 דקות. לכן כל קישור לקובץ ב־`assets/` כולל `?v=` עם מספר גרסה. אחרי כל שינוי בקוד מעדכנים את המספר בשלושת קובצי ה־HTML:
```sh
V=$(date +%Y%m%d%H%M); sed -i '' -E "s#\?v=[0-9]+#?v=$V#g" index.html admin.html portal.html
```
